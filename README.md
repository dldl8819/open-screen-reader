# Open Screen Reader

시각장애인을 위한 **무료 오픈소스 화면 읽기 프로그램**입니다.
Windows와 macOS에서 화면의 글자, 버튼, 그림 등의 정보를 **음성**과 **점자**로 전달하여, 비용 부담 없이 누구나 PC를 사용할 수 있도록 하는 것을 목표로 합니다.

> **현재 상태: 기획 단계 (Pre-alpha)**
> 아직 동작하는 프로그램은 없으며, 요구사항과 설계를 정리하고 있습니다.
> 기획 단계부터 시각장애인 사용자와 개발자의 의견을 받고자 합니다.

## 왜 만드나요

화면 읽기 프로그램은 시각장애인에게 컴퓨터의 "눈"과 같은 역할을 합니다. 그러나 국내에서 널리 쓰이는 화면 읽기 프로그램 중에는 유료로 배포되는 것이 있어, 비용이 진입 장벽이 될 수 있습니다. 이 프로젝트는 누구나 부담 없이 쓰고, 함께 고쳐 나갈 수 있는 무료 대안을 만드는 것을 목표로 합니다.

## 핵심 목표

1. **정확한 화면 리뷰(Review) 기능**
   사용자가 화면의 내용을 줄, 단어, 글자, 개체 단위로 직접 탐색하며 정확하게 확인할 수 있어야 합니다.
2. **빠른 음성 출력**
   화면 정보를 사용자가 원하는 시점에 정확하고 신속하게 음성으로 출력합니다. 이 프로젝트의 가장 중요한 핵심 기술입니다.
3. **점자 출력 지원**
   점자 정보 단말기(점자 디스플레이)를 통한 출력을 지원합니다.
4. **그래픽 정보 해설**
   복잡한 그래픽이나 이미지는 주요 특징과 기능을 중심으로 요약해 설명합니다.
5. **시각장애인 전용 인터페이스**
   기본 사용자 인터페이스만으로 활용하기 어려운 응용 프로그램에는 별도의 접근성 인터페이스를 제공합니다.
6. **높은 안정성**
   자주 멈추거나 응답하지 않는 일이 없도록, 안정성을 설계 단계부터 우선합니다.
7. **응용 프로그램에 의존하지 않는 일관된 리뷰**
   Windows 버전이나 응용 프로그램 종류에 관계없이 가능한 한 폭넓게 화면 내용을 읽을 수 있도록 합니다.

## 지원 플랫폼 (계획)

| 플랫폼 | 접근성 정보 수집 방식(후보) | 음성 출력(후보) |
| --- | --- | --- |
| Windows 10 / 11 | UI Automation, MSAA/IAccessible2 | SAPI 5, Windows OneCore TTS |
| macOS | Accessibility API (AXUIElement) | AVSpeechSynthesizer |

- 점자 출력은 liblouis, BRLTTY 등 기존 오픈소스 구성요소의 활용을 검토합니다.
- 구형 Windows(98, ME, 2000, XP, 7 등) 지원은 목표에 포함하되, 현재 개발 도구와 라이브러리의 지원 범위를 확인한 뒤 현실적인 범위를 다시 정리할 예정입니다.
- 위 기술 스택은 모두 후보이며, 확정되지 않았습니다.

## 다른 프로젝트와의 관계

이 프로젝트는 독립적인 오픈소스 프로젝트이며, 기존 상용 또는 오픈소스 화면 읽기 프로그램의 소스 코드나 자산을 사용하지 않습니다. 특정 제품이나 회사와 제휴 관계가 없습니다.
